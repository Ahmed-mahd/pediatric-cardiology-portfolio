# Professor Sahar Shaker Sheta — Clinical Portfolio

A responsive Next.js portfolio for Prof. Sahar Shaker Sheta, Professor of Pediatrics and Pediatric Cardiology at Kasr Al Ainy Faculty of Medicine, Cairo University.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Checks

```bash
npm run lint
npm run build
```

See [deployment-plan.md](./deployment-plan.md) for the free GitHub + Vercel publishing steps and exact expected cost.
